The keys are the same as in the terminal version; the key bar at the bottom of the screen lists them, and F1 shows the keypad.

  • If the browser takes an F-key for itself, press Esc and then the digit: Esc 5 is F5, Esc 0 is F10. On a Mac you may need fn for F-keys.
  • Browsers keep Ctrl-W, Ctrl-N and (in some) Ctrl-Q. Use Alt-W (other window), Alt-N (next placeholder) and Alt-Q (quit) instead. Ctrl-P opens the LSE> command line for everything else.
  • Your files stay in this browser, so the tutorial resumes where you left off. Start over erases them.
